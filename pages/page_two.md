# Open Source: Open to Everyone, Including Hackers 

## What are the disadvantages of open source software? 

### Specific skills

The first disadvantage is that certain skills are needed. Even though open source software is accessible to everyone, taking part in open source projects requires a high level of technical knowledge (Heron et al., 2013). This is a barrier mainly for users, for example students without a technical background. However, the advantage described above can help here: when technical difficulties arise, people in the community can help each other.

### Security concerns

The second disadvantage is security concerns (admin-science, 2024). Because the code is publicly accessible, it is easier for hackers to identify gaps or weaknesses in the software and exploit them in a targeted way. With proprietary software, only the company itself has access to the code. This is mainly a concern from the provider’s perspective. Here, too, the large community can help, because when security concerns come up, many people are quickly at hand.
Still, this help has its limits. To monitor security gaps continuously, some projects need dedicated people whose job is to review the code all the time (SentinelOne, 2024). There are further security concerns around sensitive customer information and company data: a company has to make sure that it does not violate any personal rights.

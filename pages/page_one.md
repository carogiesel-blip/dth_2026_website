# Open Source: Stronger Together 

## What are the advantages of open source software? 

Open source software is software whose source code anyone can read, check and change. The Linux Foundation estimates that 70 to 90 percent of modern software consists of free and open source software (TechTarget, 2026), and open source code is part of many operating systems. So what are its pros and cons?

### Version history

The first advantage is the version history. Everyone knows the file names “final1”, “finalll” and “final2”, or the alternative of saving over the old file and then realising that you want an earlier version. Open source stores a snapshot of every change, so there is a transparent overview and older versions can easily be restored. This helps users, who can undo a mistake, and providers, who can bring back an older version if circumstances change. This ease of change leads to the second advantage. 

### Flexibility and agility

The second advantage is flexibility. Companies can react quickly to new requirements, such as market changes, and implement upgrades faster. This matters in the tech sector, where AI or international interdependence quickly create new challenges. The effect is long-term sustainability: the software lasts longer (Heron et al., 2013). This is mainly the provider’s perspective, since providers want a long-lasting, high-quality and up-to-date product.

### A diverse community

The third advantage is a diverse community. Open source comes from the idea of free science: sharing knowledge to reach the best possible result. Even the best developers only work from their own standpoint, so many good ideas and perspectives are lost, while people from different backgrounds can add theirs. For users, the community means learning from others and passing on their own knowledge, and working on a project together can be a connecting hobby. For providers, open source attracts technical talent, including people who at first only take part privately.
